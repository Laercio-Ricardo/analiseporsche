# 🏎️ Porsche Sales Intelligence Dashboard

> **Dashboard executivo de alta performance para análise de vendas, inteligência comercial e dados do mercado Porsche.**

## 📌 Sobre o Projeto

O **Porsche Sales Intelligence** é um painel executivo de análise de dados (Business Intelligence) desenvolvido em formato **Single Page Application (SPA)**. O sistema converte métricas comerciais complexas e conversões de câmbio em insights visuais em tempo real, permitindo aos tomadores de decisão analisar volumes de vendas, faturamento em Reais (R\$), distribuição geográfica e preferências de modelos com alta precisão.

### 🌟 Principais Destaques

* **Navegação & Interface Glassmorphism:** Topo fixo com barra executiva e marca d'água de autoria.
* **Showroom Carrossel Dinâmico:** Seletor visual interativo com modelos emblemáticos da Porsche (911 Turbo S, Taycan, Cayenne, Panamera, etc.) integrado diretamente ao filtro principal.
* **Moeda e Cotação Integrada:** Cálculos automáticos convertidos para BRL (R\$).
* **Gráficos com Rótulos de Dados Diretos:** Gráficos interativos (Chart.js) exibindo faturamento em milhões (ex: `R$ 1.2M`) e contagem exata de unidades nas fatias e barras.
* **Leitura Inteligente de Negócios:** Módulo com resumo executivo automático baseado nos filtros ativos.
* **Tabela Operacional Interativa:** Visualização detalhada das últimas transações com badges de status coloridos e ordenação temporal.
* **Design Totalmente Responsivo:** Adaptável a telas desktop, tablets e dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

* **HTML5 & CSS3:** Variáveis CSS modernas, Glassmorphism, CSS Grid e Flexbox.
* **JavaScript (ES6+):** Manipulação dinâmica de DOM e arquitetura orientada a dados no cliente.
* **Chart.js:** Biblioteca para renderização dos gráficos com plugin customizado para exibição de valores numéricos diretos.
* **Google Fonts:** Tipografia *Plus Jakarta Sans*.

## 🚀 Como Executar o Projeto

Como o projeto foi construído em uma estrutura totalmente **autônoma e standalone (Single File)**, não é necessário instalar dependências ou rodar comandos via terminal.

1. Baixe o código fonte do repositório ou o arquivo `index.html`.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).

## 🌐 Como Hospedar Gratuitamente no GitHub Pages

Para disponibilizar o seu dashboard online através do GitHub Pages:

1. Faça o commit e push do arquivo `index.html` e deste `README.md` para o seu repositório no GitHub.
2. No repositório, clique na aba **Settings**.
3. No menu lateral, selecione **Pages**.
4. Em **Build and deployment** > **Source**, escolha a opção `Deploy from a branch`.
5. Selecione a branch principal (`main` ou `master`) e a pasta `/ (root)`.
6. Clique em **Save**. Em instantes, o link público do seu projeto estará disponível!
